# Эмулятор оболочки ОС (Вариант 26)

## Общее описание

Эмулятор командной оболочки UNIX-подобной ОС
с графическим интерфейсом на tkinter.
Поддерживает загрузку виртуальной файловой
системы (VFS) из директории на диске,
выполнение стартовых скриптов и команды
навигации по файловой системе.

Все операции с VFS производятся исключительно
в оперативной памяти. Исходная директория
на диске не модифицируется.

## Поддерживаемые команды

| Команда | Описание |
|---------|----------|
| `ls`    | Вывести содержимое директории |
| `cd`    | Сменить текущую директорию |
| `cal`   | Вывести календарь на текущий месяц |
| `date`  | Вывести текущую дату и время |
| `exit`  | Завершение работы эмулятора |

### Команда ls

Выводит отсортированный список файлов и папок.

    ls              — содержимое текущей директории
    ls level1       — содержимое поддиректории
    ls /level1/level2 — содержимое по абсолютному пути

Если указанный путь не найден, выводится
сообщение об ошибке.

### Команда cd

Сменяет текущую директорию эмулятора.

    cd              — возврат в корень VFS
    cd level1       — переход в поддиректорию
    cd ..           — переход на уровень выше
    cd level1/level2/level3 — переход по пути

Поддерживаются относительные и абсолютные пути.
При попытке перехода в файл выводится ошибка
"не каталог".

### Команда cal

Выводит календарь на текущий месяц с
выделением текущего дня.

### Команда date

Выводит текущую дату и время в формате:
    Thu Oct 02 14:30:00 2026

## Параметры командной строки

| Параметр | Описание |
|----------|----------|
| `--vfs-path` | Путь к директории на диске для загрузки в VFS |
| `--script-path` | Путь к стартовому скрипту |

При запуске выводится отладочная информация
о переданных параметрах.

## Виртуальная файловая система

При запуске с параметром `--vfs-path` эмулятор
рекурсивно обходит указанную директорию и
строит дерево объектов в оперативной памяти.
Каждый узел дерева содержит имя, тип
(файл/директория), ссылки на родительский
и дочерние узлы.

Если в корне загруженной директории существует
файл `motd`, его содержимое выводится при старте.

## Стартовый скрипт

Скрипт выполняется построчно при запуске
с параметром `--script-path`. Поддерживаются
комментарии (строки, начинающиеся с `#`).
При возникновении ошибки выполнение скрипта
останавливается, выводится сообщение об ошибке.

Формат скрипта — по одной команде на строку:

    # комментарий
    ls
    cd level1
    cal
    date
    unknown_command

## Запуск

Создание тестовых данных:

    scripts\create_test_vfs.bat

Запуск без параметров:

    python -m src.main

Запуск с VFS:

    python -m src.main --vfs-path test_vfs_nested

Запуск со стартовым скриптом:

    python -m src.main --vfs-path test_vfs_nested --script-path scripts/demo_commands.txt

## Тестирование параметров

Для проверки всех поддерживаемых параметров
используйте скрипты:

    scripts\test_all.bat       — все варианты запуска
    scripts\test_minimal.bat   — минимальная VFS
    scripts\test_files.bat     — VFS с несколькими файлами
    scripts\test_nested.bat    — вложенная VFS (3+ уровня)

## Запуск тестов

    pytest tests/ -v
