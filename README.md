# Эмулятор оболочки ОС (Вариант 26)

## Описание
Эмулятор командной оболочки UNIX-подобной ОС с графическим интерфейсом на tkinter. Поддерживает загрузку стартовых скриптов и конфигурацию путей.

## Команды
| Команда | Описание |
|---------|----------|
| `ls`    | Заглушка: выводит имя и аргументы |
| `cd`    | Заглушка: выводит имя и аргументы |
| `exit`  | Завершение работы эмулятора |

## Параметры запуска
- `--vfs-path`: Путь к физическому расположению VFS.
- `--script-path`: Путь к стартовому скрипту для автоматического выполнения.
